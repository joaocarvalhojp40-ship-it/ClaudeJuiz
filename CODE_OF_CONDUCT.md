# Código de Conduta

Queremos um espaço respeitoso para todos.

## Esperamos
- Respeito e gentileza com todas as pessoas.
- Críticas ao **projeto ou ao código**, nunca à pessoa.
- Feedback construtivo e honesto.

## Não toleramos
- Ofensas, assédio, discriminação ou ameaças.
- Spam ou divulgação de dados pessoais de terceiros.
- Uso do plugin para fins ilegais ou nocivos.

## Aplicação
Os mantenedores podem remover contribuições, comentários e bloquear quem violar este código.
Denúncias: abra uma issue com o título `[CONDUTA]` pedindo contato privado.
