# 08 · Perguntas frequentes

**É um plugin de verdade ou só um prompt?**
É um plugin com agentes, skill e comando. Funciona onde o Claude suporta plugins.

**Precisa de internet?**
Não é obrigatório, mas a busca na web deixa a análise de mercado muito melhor.

**Os 4 Claudes são pessoas diferentes?**
São quatro instâncias/papéis do Claude, cada uma com personalidade e instruções próprias.

**O Mal-humorado pode me ofender?**
Ele é ranzinza, mas critica só o projeto. Se algo parecer ofensivo, é um bug: reporte.

**O Juiz sempre concorda com a maioria?**
Não. Ele pondera pelos fatos, não por votos.

**Se o veredito for "Não prosseguir", devo desistir?**
Não necessariamente. Veja as alternativas e os ajustes. Rode de novo após mudar o projeto.

**Posso avaliar um projeto que já está pronto?**
Sim. Descreva o estágio como "no ar" e informe métricas, se houver.

**Posso avaliar um projeto confidencial?**
Evite colar segredos. Descreva em alto nível. Veja o guia 06.

**Os dados de mercado são confiáveis?**
São estimativas baseadas em buscas públicas. Valide com pesquisa própria.

**Funciona em português e em outros idiomas?**
Foi escrito em português, mas o Claude entende outros idiomas. Traduza os arquivos se quiser.

**Posso usar comercialmente?**
Sim, a licença MIT permite. Mantenha os avisos de copyright e o `NOTICE`.

**Posso criar um fork e vender?**
Sim, respeitando a MIT. Não use a marca "Claude" como se fosse afiliado à Anthropic.

**Como sei que não há código malicioso?**
O repositório só tem texto. Confira os arquivos, veja o guia 06, seção 7.

**Quanto custa?**
O plugin é gratuito. O uso do Claude segue o seu plano.

**Como contribuir?**
Leia `CONTRIBUTING.md`.
