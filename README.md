## Leitura rápida (2 minutos)
1. Instale o plugin ([02](02-instalacao.md)).
2. Digite `/julgar` seguido da descrição do projeto.
3. Receba 3 pareceres e o veredito do Juiz.
4. Leia a seção de segurança ([06](06-seguranca-e-privacidade.md)) antes de colar qualquer coisa sensível.
